# Security Policy

Banana is a community-maintained project. Security reports are handled on a best-effort basis by volunteers, and there is
no guaranteed response or fix time.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub private vulnerability reporting: open the repository's
**Security** tab and choose **Report a vulnerability**. If that option is not available yet, open a public issue that
asks for a private contact channel, and do not include any details of the vulnerability in it.

Do not report vulnerabilities in public issues or pull requests.

## What to include

- The affected version, or the commit you tested.
- A description of the problem and its impact.
- Steps to reproduce, or a proof of concept.
- Your browser, your Solr or Fusion version, and any relevant configuration.
- Any suggested fix, if you have one.

## Supported versions

Fixes are made against the latest release. Older versions are not maintained.
